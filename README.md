
### Purpose
This project focuses on developing a simple banking system with essential transaction functionality using Python and Tkinter, while enhancing our practical experience in Python programming and Agile project management.

### Features
- Account creation and management
- Deposits and withdrawals
- Balance inquiries
- Transaction history tracking
- Simple graphical interface built with Tkinter
- Input validation and basic error handling

### Learning Objectives
- Strengthen Python fundamentals
- Practice building desktop GUI applications
- Apply Agile workflows (sprints, stand-ups, task tracking, product manager, scrum master)

### Tech Stack
- Python
- Tkinter
- Git/GitLab
- Agile methodology
